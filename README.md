# Fresh Mart Faridpur (ফ্রেশ মার্ট ফরিদপুর) 🛒🌿

> ফরিদপুরের প্রথম ও বিশ্বস্ত রেডি-টু-কুক অনলাইন শপ — কাটা ও ধোয়ার ঝামেলা শেষ, ঘরে বসেই সব ফ্রেশ!

Fresh Mart Faridpur হলো একটি আধুনিক, দ্রুতগতির রেডি-টু-কুক গ্রোসারি ও তাজা খাদ্য সামগ্রী ডেলিভারি প্ল্যাটফর্ম। এখানে গ্রাহকরা টাটকা শাকসবজি, দেশি মাছ, মাংস ও বাটা মসলা সরাসরি পছন্দ করে সহজে এক ক্লিকে WhatsApp-এর মাধ্যমে হোম ডেলিভারির অর্ডার দিতে পারেন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- **সম্পূর্ণ রেসপনসিভ ও ফুল-স্ক্রিন আধুনিক ইউআই (Edge-to-Edge Fluid Design)**
- **গ্র্যান্ড হিরো ক্যারোসেল (Panoramic Hero Slider):** অ্যানিমেটেড ফ্লোটিং ব্যাজসহ আকর্ষণীয় ব্যানার।
- **ডিরেক্ট প্রোডাক্ট ক্যাটালগ (Quick Order Catalog):**
  - ক্যাটাগরি ফিল্টার (`সকল সেরা পণ্য`, `শাকসবজি`, `তাজা মাছ`, `মাংস ও চিকেন`, `বাটা মসলা`)।
  - পরিমাণ নির্ধারক (`[-] [০১] [+]`)।
  - সরাসরি WhatsApp ইনস্ট্যান্ট অর্ডার ইন্টিগ্রেশন।
- **ডায়নামিক ফ্লোটিং কার্ট বার (Floating Bottom Cart):** একাধিক পণ্য একসাথে নির্বাচন করে মোট সংখ্যা ও টাকার স্বয়ংক্রিয় হিসাবসহ একসাথে অর্ডার পাঠানোর সুবিধা।
- **বিস্তারিত প্রোডাক্ট পেজসমূহ:** ৭০+ রেডি-টু-কুক পণ্যের জন্য এসইও ফ্রেন্ডলি ডেডিকেটেড ল্যান্ডিং পেজ।
- **মাল্টি-থ্রেডেড লোকাল প্রিভিউ সার্ভার (`serve.py`):** কাস্টম রাউটিং ও ক্যাশিং সাপোর্টসহ।

## 📁 প্রজেক্ট স্ট্রাকচার (Project Structure)

```text
Fresh Mart Faridpur/
├── index.html                   # হোমপেজ (হিরো স্লাইডার, ডিরেক্ট অর্ডার ও ফিচারসমূহ)
├── products.html                # সম্পূর্ণ পণ্য ও মূল্য তালিকা
├── about.html                   # আমাদের গল্প ও পরিচয়
├── gallery.html                 # কাজের ভিডিও ও গ্যালারি
├── contact.html                 # সরাসরি যোগাযোগ ও ডেলিভারি তথ্য
├── product-*.html               # ৭০+ আলাদা প্রোডাক্ট ডিটেইলস পেজ
├── serve.py                     # লোকাল প্রিভিউ সার্ভার (ThreadingHTTPServer)
├── css/                         # স্টাইলশিট (home.css, style.css)
├── js/                          # স্ক্রিপ্টস (main.js)
├── assets/                      # অপটিমাইজড ইমেজ, আইকন ও লোগো
├── tools/                       # ক্যাটালগ ও রিলিজ বিল্ড টুলস
└── data/                        # ক্যাটালগ ও সোশ্যাল মিডিয়া ডাটা
```

## 🚀 লোকাল সার্ভার চালানো (Run Locally)

```bash
# Python দিয়ে লোকাল সার্ভার চালু করতে:
python serve.py 8000
```
ব্রাউজারে ভিজিট করুন: **http://localhost:8000** অথবা **http://127.0.0.1:8000**
